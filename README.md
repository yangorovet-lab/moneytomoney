# moneytomoney — автономный контент-сайт с партнёрскими ссылками

Приложение каждый день само:

1. берёт следующую тему из `topics.txt`;
2. пишет статью через Claude API (`claude-opus-5`) по правилам честности: без выдуманных тестов, отзывов и статистики;
3. проверяет качество (объём, фразы вида «мы протестировали», неизвестные товары, «сырые» ссылки) и отправляет подозрительные статьи в черновики;
4. вставляет партнёрские ссылки с `rel="sponsored"` и дисклеймером;
5. собирает статический сайт (sitemap, RSS, robots.txt, страницы About/Disclosure/Privacy) и публикует его на GitHub Pages.

## Честно про 300$ в день

Этот код не гарантирует доход. Он даёт бесплатный хостинг, ежедневный выпуск статей и правильную техническую основу. Сколько сайт заработает, решают ниша, качество статей и поисковый трафик.

Примерный расчёт:

- 300$/день ≈ 9 000$/мес.
- Партнёрский контент-сайт обычно зарабатывает около 10–50$ с каждой 1 000 посетителей (зависит от ниши и программы; у Amazon комиссия в основном 1–4%).
- При 20$ на 1 000 визитов нужно примерно 450 000 визитов в месяц, то есть около 15 000 в день.
- Новые сайты первые 6–12 месяцев получают из поиска почти ноль. Многие так и не доходят до 1 000 визитов в день.
- Google пессимизирует массовый автоматический контент без пользы для читателя ("scaled content abuse"). Поэтому сайт выпускает одну статью в день, а не сотни, и отбраковывает подозрительные статьи в черновики. Если хотите проверять каждую статью сами, поставьте `auto_publish: false` в `site.yaml`.

Что реально повышает шансы: узкая ниша с дорогими товарами и хорошими комиссиями, темы с покупательским намерением («как выбрать», «X vs Y»), ваша собственная экспертиза и правки в статьях, ссылки на сайт из соцсетей и форумов.

Расходы: GitHub Pages и Actions бесплатны, одна статья стоит примерно 0,1–0,3$ в API (при одной статье в день это около 3–9$ в месяц).

## Что уже решено

- **Ниша:** эргономика и оборудование домашнего офиса, сайт на английском («Desk Setup Guide»). Причины: товары дорогие (кресла, столы, мониторы), у запросов вроде «как выбрать» высокое покупательское намерение, а сам англоязычный рынок платит за партнёрский трафик больше.
- **Партнёрка:** Amazon Associates. Ссылки ведут на категории (кресла, столы, кронштейны и т.д.), а не на конкретные модели, поэтому статьи не устаревают, когда товар исчезает.
- **Контент:** 88 статей уже написаны. 8 опубликованы сразу, ещё 80 выходят по одной в день с 26 сентября по 14 декабря 2026. Каждая статья ждёт своей даты (поле `date`), а ежедневная сборка сама выпускает следующую, API-ключ для этого не нужен. Под каждой статьёй есть блок «Related guides» со ссылками на похожие опубликованные статьи.
- **Шаблоны:** раздел Templates с пятью продуктами (см. ниже). Бесплатный чек-лист собирает посетителей, а под каждой статьёй показывается самый подходящий платный шаблон.
- **Режим:** `auto_publish: true`. Статьи без найденных проблем публикуются сами, подозрительные уходят в черновики.

## Шаблоны (второй источник дохода)

Сайт продаёт собственные цифровые шаблоны. Их собирает код в `autosite/products/`, а описания и цены лежат в `products.yaml`.

| Шаблон | Цена | Формат |
|---|---|---|
| Ergonomic Home Office Setup Checklist | бесплатно | PDF, 2 стр. |
| Home Office Planner (калькулятор высоты стола и кресла, бюджет, аудит рабочего места) | 9$ | Excel / Google Sheets |
| Remote Work Weekly Planner | 7$ | PDF, 4 стр. |
| 5-Minute Desk Stretch Routine | 4$ | PDF, плакат и карточка |
| Complete Home Office Bundle (всё платное вместе) | 15$ | zip |

Как это работает:

- **Бесплатный чек-лист** можно скачать прямо на сайте. Он стоит на главной и под статьями, пока платные шаблоны не подключены.
- **Платные файлы** никогда не попадают ни на сайт, ни в git (папка `dist/` в `.gitignore`, это проверяет тест). На сайте видна только превью-картинка с водяным знаком.
- **Под каждой статьёй** автоматически показывается самый подходящий платный шаблон. Например, под статьёй о боли в шее — комплекс упражнений, под статьёй о столах — планировщик.

Чтобы включить продажи:

1. Соберите файлы: `python -m autosite products`. Они появятся в `dist/products/`.
2. Заведите продавца на платёжной площадке, которая выдаёт файл после оплаты. Для покупателей по всему миру подходят Gumroad, Payhip или Lemon Squeezy. Какая из них работает для вас, зависит от страны, где вы получаете выплаты.
3. Создайте там 4 товара (планировщик, недельный планер, упражнения, набор) и загрузите соответствующие файлы.
4. Вставьте ссылки на оплату в `checkout_url` в `products.yaml` и закоммитьте. Кнопка «Coming soon» сменится на «Buy now».

## Что можете сделать только вы (примерно 30 минут, один раз)

Эти шаги требуют вашего аккаунта, личности или оплаты, поэтому я не могу их выполнить.

1. **Сделать репозиторий публичным.** GitHub Pages на бесплатном тарифе не работает с приватными репозиториями: Settings → General → Danger Zone → Change visibility → Public. Секретов в коде нет. Альтернатива: GitHub Pro.
2. **Включить Pages:** Settings → Pages → Source: **GitHub Actions**.
3. **Слить pull request в `main`.** После этого сайт соберётся и откроется по адресу https://yangorovet-lab.github.io/moneytomoney/.
4. **Google Search Console** (https://search.google.com/search-console): добавьте сайт по префиксу URL, выберите подтверждение через HTML-тег, вставьте код в `google_site_verification` в `site.yaml`, затем отправьте `sitemap.xml`. Без этого Google будет находить сайт намного медленнее.
5. **Amazon Associates** (https://affiliate-program.amazon.com): подайте заявку с адресом сайта, когда на нём будет 10–15 статей (это примерно через неделю). Полученный тег (вида `name-20`) впишите в `amazon_tag` в `site.yaml`, и ссылки появятся на всех страницах. Условие Amazon: 3 продажи за первые 180 дней, иначе аккаунт закроют и можно подать заявку снова.
6. **Ключ Claude API** для новых статей каждый день: получите ключ на https://platform.claude.com и добавьте его в Settings → Secrets and variables → Actions → New repository secret с именем `ANTHROPIC_API_KEY`. Без ключа сайт всё равно работает, просто новые статьи не появляются.

## Проверка время от времени (по желанию)

```bash
pip install -r requirements.txt
git pull
python -m autosite status            # опубликовано / черновики / сколько тем осталось
python -m autosite publish SLUG      # одобрить черновик после правки
git commit -am "Publish articles" && git push
```

Когда темы в `topics.txt` заканчиваются, допишите новые. Лучше всего брать их из отчёта «Запросы» в Search Console: это то, по чему вас уже находят.

## Как смотреть трафик

| Что хочется знать | Где смотреть |
|---|---|
| Сколько людей заходит, на какие страницы, из каких стран и с каких сайтов | **Cloudflare Web Analytics**: бесплатно, без cookie и баннеров о согласии |
| По каким запросам Google показывает сайт, сколько показов и кликов | **Google Search Console**: подключение описано выше |
| Продажи шаблонов | кабинет Gumroad / Payhip / Lemon Squeezy |
| Клики и заработок с Amazon | кабинет Amazon Associates, раздел Reports |

Как подключить Cloudflare Web Analytics (5 минут):

1. Зарегистрируйтесь на https://dash.cloudflare.com (бесплатно).
2. Откройте Analytics & Logs → Web Analytics → Add a site → введите `yangorovet-lab.github.io`.
3. Cloudflare покажет код со строкой `data-cf-beacon='{"token": "abc123..."}'`. Скопируйте только сам токен.
4. Вставьте его в `site.yaml` в строку `cloudflare_analytics_token: "abc123..."` (или пришлите мне).
5. Первые данные появятся в кабинете Cloudflare в течение часа после первых посещений.

## Команды

| Команда | Что делает |
|---|---|
| `python -m autosite generate [--count N]` | написать N статей из очереди тем |
| `python -m autosite build` | собрать сайт в `public/` |
| `python -m autosite run` | generate + build |
| `python -m autosite status` | сколько статей уже на сайте, сколько ждут своей даты, черновики, остаток тем |
| `python -m autosite publish SLUG... / --all` | одобрить черновики |
| `python -m autosite products` | собрать файлы шаблонов в `dist/products/` |

Посмотреть сайт локально: `python -m autosite build && python -m http.server -d public`. Если `base_url` содержит путь (например, `/moneytomoney`), для локального просмотра временно поставьте `base_url: "http://localhost:8000"`.

## Структура

```
site.yaml                 настройки сайта, ниши и товаров
topics.txt                очередь тем
products.yaml             шаблоны: названия, цены, ссылки на оплату
content/                  статьи в Markdown (черновики и опубликованные)
autosite/generator.py     генерация статей через Claude API и проверка качества
autosite/affiliate.py     вставка партнёрских ссылок
autosite/builder.py       сборка статического сайта
autosite/products/        код, который рисует PDF и Excel-шаблоны
autosite/shop.py          раздел Templates: превью, бесплатные файлы
autosite/templates/       HTML-шаблоны
.github/workflows/        ежедневный запуск и деплой
tests/                    тесты (python -m pytest)
```

## Юридический минимум

- Дисклеймер о партнёрских ссылках стоит в начале каждой статьи со ссылками и в подвале сайта. Этого требуют FTC и большинство партнёрских программ.
- Некоторые программы, например Amazon Associates, требуют отдельную формулировку и запрещают указывать цены без их API. Сверьтесь с правилами своей программы.
- Не добавляйте в `facts` того, чего нет в официальных характеристиках товара.
